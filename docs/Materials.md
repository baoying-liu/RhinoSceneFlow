# v0.8 真实世界 UV 与材质

选中物件后执行 `RhinoSceneFlowMaterials`，打开简洁材质窗口，固定本次选择；底部选择“应用到该物体 / 应用到该物体所在图层”。生成页包含描述、参考图片文件和结果，尺寸 / 铺贴参数位于另一页；完整管理窗口使用 `RhinoSceneFlowMaterialLibrary`。原有视图导出工作台命令 `RhinoSceneFlowPanel` 保留。

## 先计算 UV，再应用材质

`RhinoSceneFlowWorldUV` 可单独给所选物件计算真实世界 UV，不分配材质。通道 1 中 U / V 每增加 1 对应 1 米；贴图宽高通过材质自身 UVW 变换控制。切换 600×300 mm 与 1×1 m 材质会复用相同的物件 UV。

点击“应用材质”会预检全部目标，然后分物件检查 / 补算 UV，显示实际完成数量、计算数与复用数，最后赋材质。缺失记录、几何 CRC 改变、模型单位变化、映射参数 / 映射变换被外部修改都会使记录失效；旧版按资产尺寸建立的映射会在首次应用时迁移。不能把普通已有 UV 直接当成米制 UV。

有效 UV 以已有投影为准，换材质不改变投影。要调整方向等参数，在“尺寸与铺贴”页点击“计算 / 更新真实世界 UV”；它会强制重算。更改材质宽高后保存并重新应用即可，无需重算 UV。简洁窗口采用每个物件一个 UI timer 步骤，允许在步骤间取消，已完成步骤可用 Rhino 撤销。单个复杂物件的网格计算仍在 UI 线程，期间可能短暂等待；没有虚构连续百分比。

图层范围指启动时所选物件直接所属图层的现有物件，不递归子图层；只接受可编辑面 / 网格 / SubD，遇到不支持的目标会在预检中拒绝。生成期间切换 Rhino 选择不改变原操作目标；再次执行命令可切换目标。

参考图片通过“＋参考图片”选择 PNG / JPEG，最多 8 张，复制到任务目录。Agent 可通过 `material_generation_progress` 上报真实阶段，面板显示阶段与已用时间；无人接手时显示等待。当前没有嵌入 GPT 原生网页或自动常驻生成执行端，也未实现参考图粘贴 / 拖拽。生成完成后确认尺寸并点击应用，不自动覆盖模型。

## 导入与管理

选择 Base Color 图片，输入**整张图片**代表的宽高（面板单位 mm），点击“导入为新材质”。可同时提供 Roughness、Metallic 和 OpenGL RGB Normal；格式为 PNG / JPEG，每边 2–8192 像素。粗糙度 / 金属度数值范围 0–1。没有相应贴图时使用数值，AI 生成的颜色图片不冒充测量得到的完整 PBR 数据。

例如图片横向包含 4 块 600 mm 地砖，图片宽度应为 2400 mm。像素分辨率不决定物理大小；尺寸需要用户或已知参照标定。面板按所填物理比例显示单张或 3×3 重复预览，便于人工检查图案与接缝，不承诺生成图片天然完全无缝。

每个资产有稳定 ID、名称、分类、标签、米制物理尺寸、推荐映射、PBR 参数、来源、提示词、修订号、相对贴图路径与 SHA-256。图像复制进材质库后不可通过参数保存替换；要换图片请导入为新资产。修改名称 / 尺寸 / 参数用“保存尺寸 / 参数”，来源与生成提示词保留。应用前如尺寸尚未保存，会明确阻止，避免看起来填了新尺寸却应用旧尺寸。

贴图文件名包含资产 ID 前缀。本次测试的 Rhino 8 对不同目录中的同名图片出现串图；唯一文件名及多材质交替模拟回归用于避免这一问题。

默认库位于系统文档目录 `RhinoSceneFlow/Materials`，可切换文件夹。导出 ZIP 材质包再到另一台电脑导入，可保留尺寸 / 图像并产生新资产 ID，避免覆盖。ZIP 使用相对路径和校验值；不依赖原电脑图片路径。Rhino 文档内的贴图引用仍指向本机导入后的库，换电脑时需带上材质包并重新关联 / 应用，不能只复制 3dm 就假定所有外部图片随行。

## 应用与映射

选择资产，选择当前选中物件或指定图层，再选映射方式、轴向、旋转、偏移和起铺原点。“检查应用范围”只预检目标和换算后的尺寸，不修改模型。

- 平面：可自动识别面方向；自动方向会统一相反法线的投影方向，便于相邻共面物件连续铺贴。
- 箱式：使用各面独立的平面投影和自定义映射网格，保留矩形贴图在顶面、侧面的宽高比例。这个网格只用于纹理映射，不替换 Brep / SubD / 原始 Mesh。
- 圆柱：识别真实圆柱的轴与半径，按弧长和轴向距离重复。当前针对圆柱侧面，不处理端盖的独立拼接。不能识别的自由曲面会要求改选其他模式。
- 自动：单一平面优先平面、可识别圆柱优先圆柱，其余箱式。复杂曲面不做 xatlas 展开；箱式分区可能有接缝，球面 / 双曲面不保证无拉伸连续包裹。

连续铺贴使用共用物理原点；“以每个物件为起点”使用各物件边界起点。平面 / 箱式可输入 XYZ 原点，圆柱沿用自身轴心，通过旋转、U 偏移调整接缝，通过 V 偏移调整高度。

内部全部以米存储，应用时换算到 Rhino 的毫米、米、英寸、英尺等模型单位。没有标准单位的文档会拒绝处理。所有图像通道共用映射通道 1；已有该通道的映射会备份到对象属性中，不更改其他映射通道。不能安全备份的原映射类型会拒绝替换。

“应用尺寸棋盘格”用于检查重复次数，整张棋盘对应资产宽高；之后点击“应用材质”换回贴图。图层应用会设置图层材质并将现有目标对象设为 By Layer，分别配置映射。块实例、参考 / 锁定对象、曲线等暂不支持。

移动、缩放、改变模型单位或修改几何后，使用“重新映射 / 同步尺寸”。物件模式更新已有绑定的映射并保留材质来源；图层模式重新同步图层现有对象，也为新增对象配置映射。新对象会继承图层材质，但在同步前不能保证已有真实尺寸映射。粗糙度等材质参数改变后需再次应用材质；重新映射只负责尺寸和映射。

## 恢复

支持 Rhino 原生撤销记录，并提供“恢复应用前材质与映射”。首次计算 UV / 应用时保存原材质来源、材质引用、通道 1 映射及变换；反复应用不会覆盖最初备份。恢复保留后来修改的名称、颜色、所属图层等其他属性。图层恢复需要选择图层模式，以同时还原图层材质。

备份使用显式的映射类型、变换、投影参数和必要的自定义网格；没有使用当前 Rhino 无法正确往返读取的 `TextureMapping.ToJSON / CommonObject.FromJSON` 组合。平面、箱式、球面、圆柱、表面参数和网格映射受支持，其他原映射会在预检中拒绝。

## AI 与 Agent

面板输入描述与物理尺寸，点击“请求 Agent 生成”会建立一个等待任务。**此按钮不会单独调用付费 API，也不代表图片已经生成。** 请让连接的 Agent 处理待生成任务；Agent 读取提示词、调用图像工具、将本地图片回填后，面板会自动刷新并选中新材质。也可直接导入已经生成的图片。

任务状态为 pending、completed、cancelled。可取消等待任务；已取消或完成的任务不能再次回填。材质库记录 `ai-agent` 来源与提示词。当前无内置云服务密钥、独立 MCP 服务、ComfyUI 或后台常驻 Codex 进程。无人处理任务时会保持等待，软件不会把它标成完成。

公开 API 仍通过原厂 Rhino-MCP-Platform 的 `run_python` 调用 `McpApi.Execute(JSON)`。材质操作及示例见 [MCP.md](MCP.md)。`material_library` 返回资产、库目录和调用约定；`describe.materialLibrary` 提供操作发现入口。

本次使用内置 imagegen 生成浅暖灰石灰岩示例，按整张 1×1 m 入库。项目源图在 `artifacts/materials/source/ai-limestone-basecolor.png`，完整生成提示词在同目录 `ai-limestone-prompt.txt`。它是颜色贴图示例；未虚构 Normal / Roughness 测量数据。

## 验证入口

`Build.ps1` 包含材质资产物理尺寸、相对路径、修订、包跨库导入、校验值、路径穿越拒绝等核心回归。`Test-MaterialLibrary.py` 在 B 生成独有测试物件，并验证真实 Rhino PBR、各类映射的单位重复量、旋转、恢复、图层继承、物件缩放后重算、英制换算、材质包和真实 Eto 按钮 / Agent 回填。测试只清理自身标记的物件，保留原有模型。

材质显示使用原生 Rhino PBR。原来的“材质 / 图层色”PSD 通道仍是平涂图层 RGB；需要贴图外观时，在导出工作台添加 Rendered 等原生显示模式图层。
