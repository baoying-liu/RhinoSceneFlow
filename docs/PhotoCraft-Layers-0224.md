# PhotoCraft 图层与画布标注 · 0.22.4

右侧“编辑与标注”统一管理外观编辑层与特殊标注。普通图层合成到一份可替换的外观参考；特殊层按固定 ID 更新原来的画布标注/参考资源，不混入外观合成。

## 使用方式

- 眼睛控制页面预览，不改变生成输入、黄色状态或输出文件。AI 复选框控制是否参与下一次生成。
- 顶部控制全部，特殊标注组也有自己的总开关。关闭总开关不会清空各层设置，重新打开时保留原值。
- 已完成且锁定的图片可以切换显示；修改 AI 参与或打开 PhotoCraft 前需要解锁。面板有直接解锁入口。
- 右侧行与画布实体双向选择；返回的特殊层提供缩略图。列表预览也可单独显示/隐藏标注；对比右侧的输入图与文件导出保持原始像素。
- PhotoCraft 的 `SceneFlow Instructions [SF1]` 内保留 pen、arrow、text、label、edit、protect、reference 七个类别分组。已有标注逐项对应 `[SF:类型:固定ID]` 图层，可以修改名称后半部分，不能改前缀。
- 删除具体标注图层会删除对应标注/参考资源。系统分组不能缺失；PhotoCraft 原生界面仍可删除它，但返回会被拒绝，需要撤销后再应用。此项是宿主校验，不假称原生编辑器强制防删。
- 在系统分组外做普通绘画/编辑。重新打开时保留普通图层，并根据当前画布重建特殊层，避免旧项目中的标注覆盖新画布。

## 数据与生成

编辑工作区包含图片与考虑框的外部区域，固定像素偏移与比例随会话保存。返回时独立解析特殊层和普通外观，原始素材与生成备份不被覆盖。

没有改动的特殊层保留矢量/文字；像素涂改后的特殊层以原类型的栅格指令和位置返回，不伪造文字识别或箭头端点。它们会出现在生成空间示意图中；修改/保护区使用返回的 alpha 生成蒙版，保护最后应用。若要继续按文字字符编辑，未栅格化的文字仍可直接在画布编辑；已涂改的文字需要在 PhotoCraft 修改，或在画布重建文字。

普通外观声明与特殊指令声明分开保存。显示状态不参与上下文签名，AI 启用状态参与。会话检查源图版本、当前参考槽及考虑框/标注内容，异步解析期间内容发生变化会拒绝返回；仅切换眼睛不会造成误报。

具体标注/参考资源的内容修改与删除进入画板撤销/重做；外观参考槽仍独立于画板撤销与图片备份。停用本图已有的外观槽，不会隐式启用父图的外观槽。

当前普通返回支持像素/文字层、蒙版与 Normal/Multiply/Screen/Overlay/Darken/Lighten；不支持的效果、调整层与剪贴关系要求先栅格化，避免静默错误。系统标注层要求 Normal 混合，类别容器保持 100% 透明度、无蒙版和效果。
