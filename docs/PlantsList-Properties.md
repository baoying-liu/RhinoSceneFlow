# Plants List 与属性（v0.17.4）

命令 `RhinoSceneFlowPlantsList` 打开当前文档的组合列表；`RhinoSceneFlowProperties` 打开跟随选择的属性工具。两者为原生 Eto System Panel，可以独立停靠、组合或浮动。工作区导航也可以切换到这两个工具。素材图片仍在共享植物库，Plants List 只管理当前文档中的种植组合。

列表支持搜索、多选，以及与 Rhino 视口双向选择。右键可重命名、移动图层、显示、隐藏、锁定、解锁与定位。隐藏和锁定的对象仍在列表中；所在图层关闭或锁定时，仍需恢复图层状态。对象隐藏前的锁定状态由插件保留，恢复显示时继续锁定。列表修改写入原生对象属性并支持 Undo。

双击列表组合进入隔离编辑，也可在视口双击植物进入。整个组合根物件及外部正常物件会临时锁定，原生整体选择清空；视图旋转、缩放和参照几何仍保留。单击植物的非透明部分选中一株，绿色轮廓表示当前单株，并显示专属 Gumball。拖动操作柄移动或等比缩放；Ctrl 拖动或属性中的“复制此株”只增加当前组合中的一株，不会复制整个组合。不生成临时文档物件。移动的落点重新附着承载面，树保持朝上；水平镜像和类型在单株属性中调整。

编辑时外围几何锁定并灰显，当前组合保持植物颜色；外围其他植物组合也灰显。灰色只覆盖当前绘制帧，不修改模型材质、物件颜色或图层颜色。拾取射线按相机朝场景的方向计算，透明度门槛和预览一致；线框／Xray 不把背景面当作不透明遮挡。列表刷新产生的临时空选择不会再退出编辑。

属性工具顶部提供“完成并退出”和“取消本次编辑”。双击视口中未命中当前植物的空白处也会完成并退出；前者及双击保留修改，取消恢复进入时的组合参数。退出恢复外部物件原先的锁定和显示状态。原生保存会先完成编辑；PSD 导出和整体组合参数修改要求先退出。编辑锁标记支持保存前清理、重新打开和 Undo/Redo 后恢复。此模式使用 Rhino GumballDisplayConduit/GetTransform，并非 Rhino 的 BlockEdit 命令或真正块定义。

单株修改会保留其余植物的布局；复制增加一株。之后显式改变密度、布局种子、组合素材、手工点、承载面几何或文档单位时重新计算布局，自定义植株继续作为固定成员参与密度和间距计算。参数快照使用 Rhino 原生自定义 Undo 记录，回放完成后恢复，避免后台显示网格更新破坏参数的撤销关联。

拖动时缓存背景移除正在移动的原株，只动态绘制该株的贴图和轮廓，固定这一轮拖动的预览精度，避免旧位置残留和切换精度造成停顿。Ctrl 复制保留原株。预览采用 Rhino 标准前景反馈，松手后立即提交到承载面并恢复正式深度遮挡。载体、布局设置和单位未变化时，位置／大小／镜像等单株编辑立即更新显示与操作柄，不再等待整组布局定时重算；承载面或整体参数变化仍使用原有后台流程。

选择轮廓仅在界面前景绘制，保留深度测试以遵循遮挡，但不写深度、不投影；真实植物网格仍使用原有绘制和阴影。此分离修正了原先在 PostDrawObjects 绘制轮廓线造成的离体灰色投影。绘制阶段说明见 [Rhino DisplayPipeline](https://developer.rhino3d.com/api/rhinocommon/type/rhino.display.displaypipeline/)。

修改单株会记录独立身份、曲面附着、类型、比例和镜像；更换类型默认保持高度。自定义植物计入密度与间距，改变组合随机种子、密度或移除组合中的该物种不会删除它。曲面保持拓扑时依附参数跟随；无法重新匹配时保留位置并标记待附着。整体组合变换仍作用于自定义植物。关闭自定义或“恢复组合设置”移除独立覆盖：手工种植回到其原始附着，自动植物回到当前布局种子的程序结果，因此原位置不保证仍存在。

普通物件的属性显示 UV 与材质设置。UV 默认自动，选中本身不展开；应用局部材质修改前检查选中物件的 UV，必要时进入已有异步准备队列。修改材质默认影响当前文档中使用同一原生渲染材质的对象；物体和图层范围在共享可能影响范围以外对象时复制材质，独立后重复编辑复用已有材质。图层范围将该图层的普通对象统一为选中物件的有效材质；植物不参与。仅应用已勾选或修改的字段，避免多选时覆盖不同值。库中图片与元数据不会因此改写。

当前属性支持原生 PBR 的粗糙度、金属度、材质名称和贴图实际宽高。原生贴图通道仍可能覆盖常数；非 PBR 或第三方渲染器专有字段需要使用其原生编辑器。相同材质依据当前文档的有效渲染材质身份判断，不会按素材名称把不同变体重新合并。原生渲染内容直接参数修改使用 Rhino 原生 ContentUndoHelper，保留名称、PBR 常数和纹理重复；不借此修改素材库。

MCP 继续依赖原厂 Platform，无新监听端口。列表、组管理、编辑状态和单株修改均有公共 API，见 MCP.md。回归脚本使用独立的合成 PNG 测试库；这些图片不是 AI 生成植物，也不会导入用户素材库。
