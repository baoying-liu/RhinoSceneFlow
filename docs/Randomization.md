# 材质随机去重复（v0.14.0）

AI 材质与独立材质库下都有「随机去重复」折叠区。新生成图片入库时，实际图片会交给分类模型，返回建议方式、理由、是否允许旋转，以及结构网格。默认选择「自动 · 使用 AI 建议」，可以手动改方式、种子、色差、周期及结构网格。「应用」自动保存这些设置、准备贴图，再执行必要的真实尺寸 UV 和材质应用；「保存并预览」只准备缓存并显示 Rhino 原生球体。既有材质默认关闭，不批量改变旧外观。分类失败保留图片，关闭随机并提示待分类，不伪造 AI 建议。

| 方式 | 实现与用途 |
| --- | --- |
| 按物件随机 | 稳定的物件 ID/种子决定平移、旋转和色差；适合独立木板、石块。应用到图层时，对当前物件建立外观变体；后来新增物件需重新应用。 |
| 随机平铺 | 周期网格内随机采样同一材质，平滑插值，在线性颜色空间修正混合方差；适合无方向的泥土、砂石、混凝土。不是精确直方图保持，明显图案仍可能出现交叠。 |
| 大尺度色差 | 周期化 OpenSimplex2 低频噪声调节底色，保留原图坐标；适合连续纹理。 |
| 保留结构 | 原图坐标不变，按砖/板网格改变内部色调，网格边界保护接缝；列、行、错缝需与原图对齐。AI 网格为估计，可手动校准；不承诺识别任意不规则铺装。 |

旋转只使用等尺度变换；非正方形限制为 0/180°，不会随机拉伸改变真实尺寸。所有已有 PBR 图使用同一坐标变换，切线法线按 UV 旋转修正方向并归一化，底色使用 sRGB 转换，数据图按线性数据处理。色差只影响底色，不凭空推算新的粗糙度或法线。

本版采用兼容 Rhino 原生材质和现有 PSD 导出的**离线烘焙**，不是无限无周期 GPU shader：可选 2×2、4×4、8×8 原图周期，周期外仍重复。缓存随物理覆盖尺寸一起扩大，保持原像素密度和米制 UV；任何一边超过 8192 像素会明确失败，需降低周期或源图分辨率，不偷偷降采样。缓存存在共享材质库的 `cache/random-v1`。材质设置保存后，既有物件需重新应用；其他文档不会被后台修改。

烘焙由独立 `SceneFlow.TextureWorker` 运行，只有图片和参数快照，不持有 RhinoDoc/物件。真实逐行进度、取消、关闭文档、过期外观版本与目标变更检查均独立于 UI。PNG 校验、完整缓存身份和原子目录发布避免读取半成品；取消只终止自己启动的 worker。原图保持不变。

PSD 读取实际生效的烘焙贴图：同一材质的不同物件随机变体默认合并为一个材质图层；选择按物件导出时仍在同一个「材质」组内分开。不同材质 ID/外观版本保持分开。

第三方仅引入 MIT 的 [FastNoiseLite v1.1.1](https://github.com/Auburn/FastNoiseLite/tree/7ccfbc16eb1c932568f177d63a9ba51d89bbe516)，用于低频噪声，固定源码及许可证位于 `third-party/FastNoiseLite`。随机平铺、结构保护和 PBR 同步采样由 Core 实现；没有复制许可证不明的渲染器 shader。发布包包含该许可证。

验证入口：Core 标准验证、`Verify-RandomWorker.py`（独立 Pillow/Numpy 解码）、B 的 `Test-RandomMaterials.py` → `Check-RandomObjectExport.py` → `Check-RandomStochastic.py` → `Check-RandomAi.py` → `Finish-RandomUi.py` → `Check-RandomUi.py`，以及 `Verify-RandomPsd.py`。实际 AI 测试使用图像额度；不要无故重复执行。
