# 季节素材与视图导出（v0.22.9）

## 使用流程

AI 对话默认生成夏季素材；植物的夏季立面入库后，继续生成夏季平面。勾选“生成四季版本”会补齐四季；材质库／植物库的“季节版本”也提供补齐按钮。操作沿用原聊天、登录与 image_gen 执行器，图片输入不变。不新增生图服务或 MCP 监听端口。

素材库仍只显示一条记录：植物内部为四季 × 立面／平面，材质内部为四季底色。没有明显变化的季节引用同一个文件，不复制文件或创建重复素材记录。任务先检查已有版本；版本齐全时没有图片或文字模型调用，仅按需准备随机缓存。未齐全时由 AI 根据既有物种资料、图片与气候计划哪些季节复用夏季，哪些需要新图。植物首次识别仍走真实来源核实，后续季节任务不重写学名、分类或标签。

旧素材不会在打开文件时自动批量生图。缺失季节回退夏季；缺失平面时继续使用立面。季节版本面板显示哪些槽位存在，哪些使用回退。任务可以取消，已经成功入库的槽位保留，失败／取消不会冒充四季完成，重新补齐复用已有结果。

## 尺寸和朝向

每个植物保留参考高度（估计值），实际树高包含实例随机缩放和组合高度缩放。立面季节图先裁去透明空白、重新计算基部锚点和宽高比例；保持参考树高，避免把不同图片比例强行拉伸。平面图按冠幅（估计值）与横向缩放显示，中心对准植物位置，抬升量为实际树高 × 全局比例。切换图片不改变布局、密度、种子、个体自定义或植物数量。

默认自动规则：低角度沿 Z 轴，高角度自由朝向，75° 及以上切换平面；自由朝向中心角默认 60°，缓冲 5°，平面抬升比例 .65。角度定义为水平 0°、正俯视 90°。全局也可强制 Z 轴／自由／平面。当前平面切换为阈值切换；自由朝向采用连续过渡，不宣称两套图片做无缝形变。旧朝向参数在读入时兼容新角度范围。

`plant_instances` 的 position 始终是地面锚点，displayPosition 是显示抬升后的锚点，heightMeters 是缩放后的实际参考树高，orientation 为 plan/elevation；平面显示矩形尺寸不冒充树高。预览、植物图层、深度及植物阴影共用同一朝向／图片选择。

## 视图和 PSD

新视图默认 Rendered 预览；已有手动模式保留。双击卡片预览激活对应 Named View、显示模式及预览季节；细节调整保留单独按钮。眼睛使用真实绘制图标，带斜线为 PSD 隐藏，勾选仍独立控制是否导出。

页面大小下有独立“季节”折叠区：预览季节、跟随预览导出（默认开启）、多季节勾选。跟随开启时，多季节勾选禁用；默认夏季。季节不自动改变太阳日期。输出例如 `视图_夏.psd`、`视图_春_夏_秋.psd`。合并按该视角实际使用的图片、几何尺寸和启用通道判断；未使用的冬季立面不会拆开四季平面一致的俯视输出。不同图片仅仅看起来相似时不做猜测合并。重名继续按既有覆盖／编号规则处理。

季节材质复用现有随机贴图 Worker 和物理 UV，不修改几何／UV、原始贴图或布局。变体缓存保持相同种子和物理周期；元数据、别名、跟随开关不改变缓存身份。对象随机使用实际对象／图层 ID。已有图片可以只补缓存，不重新生图。临时预览捕获在 UI 线程切换并恢复 RDK 纹理参数、视口、文档修改标志与撤销记录；明确激活视图则显示该季节。缺少必需缓存会明确要求补齐，不静默丢掉随机效果。

## 设置与本地存储

导航的分组按钮将所有工具放入同一容器；齿轮打开统一原生设置窗口，含语言（默认跟随 Rhino）、主题（默认跟随 Rhino）、气候、默认四季生成以及植物朝向区间／抬升比例。公共导航、新设置和植物名称遵循语言选择；既有工具仍有部分中文帮助／状态文案，尚未做完整双语翻译。Web 后期的既有语言偏好仍独立。

每个素材的跟随场景季节默认开启，关闭后使用固定季节。文件保存在该素材自身目录，Map/SHA 元数据原子提交；新增图片用唯一文件名，不覆盖旧图。跨进程元数据变更按短间隔检查，缓存按库路径及素材 ID 区分；不能让切换素材库后的同 ID 误用旧版本。ZIP 包携带季节映射与所需图片。含季节图片的新素材需要 v0.22.9 及以上插件读取；旧素材可由新版继续使用。

## 验证范围

见 Validation.md 的 v0.22.9 记录。真实模型调用验证了一张罗望子平面 PNG，八季节槽位共用原夏季立面与新平面；冬季对比导出使用明确标注的合成测试图片，不冒充实际冬季 AI 质量结果。植物形态、冠幅和气候外观仍需人工复核；未验证所有物种、全部四季的真实生成质量或 4K／8K 四季性能。
