# v0.5.1：太阳直射阴影与预览窗口修复

面板的旧默认值关闭了背光面，只保留投射阴影，因此凸球体只有被其它物体遮挡的一小块阴影。现在 Named View 面板、批量 API、阴影体命令以及 `backend:"volume"` API 默认包含背光面和自身遮挡，使用统一颜色和透明背景。显式 `includeFormShading:false` 仍可输出纯投射阴影。旧 ray API 默认保留以兼容历史对照。

只计算方向太阳光的可见性，不计算反射、间接光、AO、材质高光或柔和漫反射渐变。极地/渲染显示模式仅用于模型预览，其画面光照不等于导出的阴影蒙版。没有隐式地面，实际模型表面才接收阴影。

预览不再实例化 ViewportControl。该控件在本机遗留了两个浮动 Custom view；关闭面板仍未移除。新预览用 Eto ImageView 显示 Rhino 捕获的图片，捕获时暂停重绘，并在 finally 恢复原相机、视图名、显示模式、网格、坐标轴和 Modified。不创建 RhinoView，也不改变主视图尺寸。静态预览支持切换显示模式、画幅及刷新，不再提供预览内旋转。

阴影仍用 CPU z-fail 体积法，缓存接收深度、面法线及法线变化量。完整直射阴影的内部由阴影体或背光面分类；原始曲面求交集中在明暗交界及覆盖边界。球体使用解析求交，平面仍检查修剪边界。最多四个线程处理复核，每个线程持有独立 Brep/Mesh 副本，避免共享 Rhino 的几何查询缓存。没有模糊、扩张、阈值清理，也没有为了提速降低网格密度。

精度仍受网格覆盖、源几何数值求交及 bias 限制，极小漏网特征、无效几何、SubD 极限面、透明裁切和特殊相切情形不构成保证。当前不是 GPU 或 C++ 实现。

复核脚本：`Benchmark-DirectShadow.py`、`Test-DirectShadow.py` / `Verify-DirectShadow.py`、`Test-ShadowAccuracy.py` / `Verify-ShadowAccuracy.py`、`Test-PreviewWindows.py`，以及原有面板批量、异步与取消测试。

所有文件证据位于忽略目录 `artifacts/rhino-B/direct`、`accuracy` 和 `panel`。PSD 使用独立 psd-tools 解码，没有启动 Photoshop，没有使用鼠标，没有发布到正式 Rhino。

## 精度核对

完整太阳直射阴影：两个太阳方向各 4,276 像素，共 8,552 像素、34,208 个子采样，与解析球体/双曲面/双曲抛物面及源几何参考一致，含部分覆盖边界。背光面和可见投射阴影均有覆盖。纯投射阴影的三组双曲面密集检查共 9,011 像素、36,044 子采样及两个混合接收面像素也通过。

最初新增参考有 308/627 个不一致，保留在 `accuracy/direct-reference-failures.json`。原因是地面已由旧测试场景的 Z=-2 改为 Z=0，墙顶也从 Z=10 改为 Z=12，参考公式却仍写死旧值。已改为读取实际几何；球体也从原始曲面提取解析球参数，避免用缓存网格包围盒推算半径。未改动用户模型来迁就参考。

## 同条件速度对照

当前模型 12 个对象、334,036 个三角形；重播同一相机、同一太阳方向、1024×587、包含背光面及自身遮挡、完整 PSD 写入。旧 v0.5.0 显式开启完整阴影耗时 168,719 ms、263,112 次曲面复核；最终 v0.5.1 为 15,864 ms、49,400 次复核，约 10.6 倍。601,088 个像素的阴影 alpha 与旧完整计算逐像素相同，未改变网格数量。这是当前场景实测，不代表所有模型都能达到相同比例，也不是与旧版默认的纯投射阴影作比较。
