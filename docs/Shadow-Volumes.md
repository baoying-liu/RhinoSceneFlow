# v0.4：独立阴影体后端

2026-10-22，限 RhinoDevSandbox B。新增 `RhinoSceneFlowExportShadowVolumePSD`，原命令仍调用旧射线后端，便于保留对照；旧后端已确认的平滑法线偏移漏影没有被悄悄标为修复。

## 使用

```text
_-RhinoSceneFlowExportShadowVolumePSD 1024 _Enter
```

宽度默认 2048，路径回车使用现有默认目录。太阳、颜色、透明度、实际接收面、PSD 图层及画幅规则与原阴影导出一致。不要把阴影体当作导出的实体：PSD 仍只有透明背景上的单色 `Shadow` 像素层。

原厂 Platform 的 `run_python` 调用原有 `McpApi.Execute`，请求使用 `operation="export_shadow_psd", backend="volume"`。省略 `backend` 保留旧版 `ray` 行为；返回报告新增 `backend`。未知后端明确拒绝，不自动回退。

## 实现

- Core 内的 CPU 软件 z-fail 阴影体光栅化，没有新增原生依赖、GPU 上下文、服务或端口。它采用阴影体原理，不声称复现 SketchUp 私有实现或实现其当前 Fast Shadows。
- 首先双面光栅化实际几何，保存最近可见接收面的深度和三角形编号。
- 每个非退化遮挡三角形独立形成封闭棱柱：朝光源的前盖、背盖及侧壁。所有体统一朝外。相邻侧壁通过精确顶点键和有符号计数抵消，不焊接或修补原始网格；开放面、反向面和不共享拓扑的面也可投影。相比只提取整个封闭模型的轮廓边，此方案用更多盖面换取开放面的支持。
- 沿背离太阳方向拉伸，长度超过全场景沿光轴的坐标跨度，保证背盖超过所有潜在接收面；包含相机视锥之外的投影物体。
- 统计可见深度之后的体表面穿越数，非零即处于一个或多个阴影体内部。侧面和盖面统一参与计数。阴影体不在相机远平面裁掉，否则会丢失闭合背盖；接收几何仍按完整视锥裁切。近裁剪之前的体表面无需参与 z-fail 计数。
- 覆盖使用 1/256 子采样像素网格及 top-left 边界规则，使相邻边一致；深度插值保持原始投影平面。首版未固定子像素网格时，透视平面测试出现 7 个内部错误采样，修复后为 0。保留问题描述，不将内部错误归为抗锯齿误差。
- 深度容差使用模型单位，不沿平滑法线移动接收点，不使用图像模糊、阈值或形态学清理。平滑法线仅用于可选的本体明暗。默认投射阴影资格取可见几何面朝光源的一侧；因此曲面细分及几何法线近似仍会影响分界。
- 32 位有符号计数避免常见 8 位模板计数回绕；2×2 子采样生成抗锯齿 alpha，RGB 保持单色。

阴影体和 z-fail 原理的原始技术参考：[Everitt / Kilgard, 2003](https://arxiv.org/abs/cs/0301002)。经典 SketchUp 的地面投影、面阴影体及 Carmack’s Reverse 记载见 [SketchUp 4 官方手册第 145、158–159 页](https://courses.washington.edu/udpddp/User_Guide_EN_WIN.pdf#page=145)。本实现的逐三角形封闭体与侧壁抵消是本项目自己的工程选择。

原漏影反例中，两组几何完全相同，仅接收面顶点法线不同。旧后端平滑法线版中心 alpha=0、几何法线版=255；新后端两者均为 255，恢复应有的近接阴影。

同一 1024×524 透视视图还导出移除平滑法线偏移的几何射线参考，逐像素比较：只有 2 个像素的 alpha 相差 64（一个子采样），其余一致。这个交叉比较验证两种网格算法的一致性，不能证明网格精确代表 NURBS。双曲面分界附近的细碎纹理在两者中都存在，仍是后续需改善的曲面近似问题，未靠平滑后处理隐藏。

独立 psd-tools 解码确认单层、单色 RGB、透明背景、仅覆盖率决定边缘 alpha、半透明样式及图层重合成（最大预乘 RGBA 误差约 0.502/255）。真实命令 128 像素导出和默认 2048 像素导出通过。Rhino Sun 实际设置 135°/45°并核对方向，自动与显式方向 PSD 字节一致，完整渲染设置恢复。

Core 验证还覆盖相机在阴影体内、跨近裁剪、背盖超出远裁剪、视野外投影物、重叠、反向面、球体及大坐标平移；九组与无平滑法线偏移的射线参考逐子采样一致（各 36,864 个子采样）。验证了空阴影、本体明暗、透明度与取消。

## 限制

这是可供对比测试的 CPU 后端，速度慢于旧射线后端，当前同步执行会阻塞 Rhino。最大输出仍为 800 万像素；子采样深度、接收编号和计数会显著增加内存。暂不采用 GPU 加速。

仍按不透明网格处理材质；植物 alpha 裁切、透明材质、软阴影、解析 NURBS、隐式地面和裁剪平面不在支持范围。比 bias 更小的间隙可能被容差合并。固定子像素网格会带来微小覆盖差异。此轮没有实现矢量阴影轮廓，也未替换旧后端。
