# SceneFlow Studio · v0.22.0

命令仍是 `RhinoSceneFlowPostProduction`。列表和画布共享同一份本机工程；旧 PSD 项目和分块工作台保留在“设置 → 高级 PSD／分块检查”。没有新增 MCP 服务。

## 使用顺序

1. 顶部导入 PSD、PNG、JPEG、WebP，或拖到中央工作区。支持本机路径、Rhino 已有导出项目及 `.sflowboard` 工程包。
2. 原始输入像素不可覆盖，保留文件后缀；其生成设置无需解锁即可调整，作为创建子级的模板。原图创建子级时复制当前描述与参数，生图成功后清空原图模板描述、保留参数。已生成图保留自己的描述及锁定状态，由它创建的子级／同级描述为空、参数继承所选图。创建只建立黄色待生成白板，不调用 AI；新节点标注与参考图为空。
3. 编辑白板后点击“更新图片”。结果写回同一节点并锁定；再次修改需手动解锁。创建同级使用所选结果的父级输入，继承所选结果的参数。更新保留历史，不覆盖原 PSD。整图维持输入像素尺寸及宽高比。
4. 需要标注时使用“在画布中显示”。手绘笔、箭头、文字、Label、修改区域／保护区域可在画布自由放置，考虑框确定对应主体的输入范围；笔压存储在笔迹点中，触摸不当作画笔。
5. 添加或粘贴参考图。参考图是独立画布资源，通过考虑框确定参与范围；只有与该生成框相交的部分参与输入，最多四张。用途可选材质、风格、形态、植物、配色等。它们会组成一张编号参考板，连同干净主体、标注图和像素蒙版送入模型，最多四个输入附件，不用挤掉主体或蒙版。
6. 满意后选中对应整图版本，切到“高清细化”，选择 1K／2K／4K 长边、分块尺寸和上下文。次数上限随设置显示。直接使用已确认整图作为统一参考，不另生成一张风格参考图。结果仍需检查设计细节和构图。
7. 被提示检查的分块不自动合并。在“历史 → 检查分块”查看、接受或重试；接受后更新对应白板并锁定。
8. 选中图导出 PNG／JPEG／WebP；混合比例影响预览和导出。标注不会进入最终图片。当前不输出分层结果 PSD。

## 双视图与保存

- 图片 ID、名称、参数、参考归属、标注、版本身份和任务共享；列表顺序与画布 pose 分离。移动图片不改名称、像素或参数。
- 右键和工具栏可双向定位。“在画布中显示”缩放到目标，“在列表中显示”滚动定位并清除阻挡目标的筛选。
- 画布有小地图、缩放、框选中的生成边界自由调整；生成框不改变输出尺寸。框外像素不修改，修改／保护笔进一步限制图内范围。
- 手绘点和注释使用主体图的局部坐标，图片移动时跟随；参考图片有独立位置。边界只决定考虑范围，不会把参考照片拼进效果图。
- 参数、布局自动保存到 `%LOCALAPPDATA%/RhinoSceneFlow/postproduction/boards`；启动恢复上次画板。中文／英文／跟随系统在设置中选择，偏好跨画板保存。
- “保存画板”下载可携带的 `.sflowboard` 包；“另存为”先建立独立画板副本，再下载。不是静默覆盖最初导入的磁盘工程包。包包含原 PSD、图片、笔迹、布局、参数、版本和任务输入记录；正在运行的进程不随包迁移。
- 归档保留图片，可恢复；“在画布中隐藏”不从列表或工程中删除。右键复制为分支使用同一不可变图片资产，后续设置独立。
- 多窗口使用 revision 检查；冲突时保留当前编辑，提供元数据恢复下载与显式重载，禁止静默覆盖。导入工程包拒绝路径穿越、链接、重复文件及不匹配的资产哈希。

## PSD 与约束

源 PSD 首次整图处理支持可修改、结构参考（可以重绘外观）、像素锁定、仅参考、排除。结构参考是生成指令约束，不是几何证明。仅源节点使用源 PSD 的可见 alpha 与像素锁定；生成子版本不重新贴回原粗模型像素。硬保护和原始 alpha 在 worker 回填时恢复。

0.23.3 起，新整图任务的干净输入和遮罩直接使用目标图片的宽高比，不再加入正方形白色留边后按固定坐标裁回。空间示意图与通道参考板仍是独立参考图，不决定输出形状。返回图片比例偏差超过 2.5% 时明确失败，不发布拉伸或猜测裁切的图片；此容差用于模型尺寸取整，不是构图保证。已保存旧任务按 prepared.json 中原有的留边坐标继续处理，不改写历史图片。正常白色背景不会被自动裁掉。高清分块的上下文补边流程不受此项修改影响。

高清源来自选定整图。扁平图没有语义 alpha 轮廓，使用可见 Canny 边缘进行距离提示；这些边缘不作为旧像素条带贴回，否则模型轻微位移会产生双边。质量检查是人工复核提示，不保证建筑几何完全不变。已确认输入直接用作统一风格，方形输入按实际上下文紧凑补边，不将小图塞进配置最大尺寸的大空白中。

## 实现与边界

前端是 React 19、react-konva／Konva、perfect-freehand；固定版本见 `web/postproduction/package-lock.json`。源码位于该目录 `src`，`npm ci && npm run build` 输出 Plugin/PostProduction 的本机 `board.js`／`board.css` 和依赖许可。运行不依赖 npm、CDN 或云白板。

Python 服务保留旧接口，新增 Store／BoardApi／文件 worker。整图通过现有 Codex ChatGPT 登录与 image-only runner；描述助手仍禁用工具，不拿文本回复冒充生图。来源检查、实际线程／新 PNG 收据与已有独立 worker 取消边界保持。没有 API Key 切换，也不声称锁定某个图像模型。

第一版支持源图边长最多 8192、每板最多 1000 图片、每图最多 1000 标注／100000 笔迹点、12 MB 元数据、2 GB 工程包。离屏画布节点不挂载，列表缩略图按可见区域读取；服务生成 256 px 缩略图，避免所有列表项都解码大图。

这是首版专用标注工具，不是完整绘画软件：现有标注可启停、删除、撤销；复杂矢量节点编辑、逐字文本排版、专业笔刷、多人协作和多指缩放尚未提供。手写笔硬件与真实浏览器触感需要实测。保存不等于任务完成；模型可能改变设计细节，检查后再采用。

## 自动化

全部 JSON 路由可通过原厂 Platform 的 `postproduction_request` 访问：

- `GET /api/boards`、`GET/PUT /api/boards/{id}`，PUT 必须传当前 revision。
- `POST /api/boards/{id}/generate {revision,node,stage:"whole"|"detail"}`。
- `GET /api/boards/{id}/tasks`；取消使用 `/api/jobs/{job}/cancel`。
- 整图未完成任务：`POST /api/boards/{id}/tasks/{task}/resume`，恢复冻结输入；已存在且哈希匹配的新图可以直接回填，不重复调用模型。
- 分块检查：`GET/POST /api/boards/{id}/tasks/{task}/review`，action 是 accept、retry、resume，前两者带 tile。
- `POST /api/boards/{id}/save` 返回本机工程包路径；`POST /api/boards/{id}/export {node,format,blend}` 返回图片路径，无需浏览器鼠标或文件对话框。
- `GET/PUT /api/board-preferences` 设置 language／lastBoard。

二进制下载仍由浏览器处理，JSON bridge 不直接传文件或 bearer。接口调用与原生图档无关，不把 RhinoDoc 交给后台线程。

## 验证

`Test-PostProductionBoards.py` 覆盖实际 HTTP、分层 PSD、结构／像素锁定区别、参考板、源哈希、导出、工程包、路径穿越、冲突与语言。`Test-BoardInvariants.py` 在阻塞的图像队列上验证提交快照和两种取消时机，不调用模型。前端 `node test-dom.cjs` 是 jsdom 组件事件测试，模拟 raster context，验证双向定位、拖动中线、语言、预设保存与无控制台错误；不等于浏览器截图或手写笔验收。

真实模型测试使用明确标注的粗略体块二维夹具：一次整图、三次高清尝试，共四次图片执行请求及四份新 PNG 收据（非账户计费统计），另一次真实文本描述。保留大留白导致放大、边界复核，以及旧 Canny 保护条带问题的证据；最终输入改为紧凑上下文，Canny 仅作诊断。最终高清仍触发人工检查，显式检查接受后合并，不能称为几何一致性证明。示例包在 `artifacts/examples/Studio-v020`，不是 Rhino 中重建的新三维模型。

## 节点工作流与溯源（v0.21）

- 列表树可折叠；画布显示有向父子连线，位置与关系独立。选择节点会自动定位，列表/画布切换重新挂载预览，加载工程时先同步选择再异步取任务，避免保留旧节点导致空视口。
- 原图永久只读；白板可编辑；成功结果锁定。黄色代表未生成/本地配置修改，紫色代表直接有效输入版本变化；文字状态同时保留脏草稿信息。解锁本身不标黄。布局、名称、折叠不影响生成配置。
- 描述、参数、生成阶段、标注、参考用途/位置/隐藏和考虑边界属于生图草稿；自动保存。撤销修改恢复最近成功配置及参考实例。生成时禁止修改内容；失败/取消保留草稿，成功锁定。锁定但上游已变化可直接更新。
- 每次更新使用最新有效父级图；固定 inputVersion、inputNotes、任务快照及实际收据。父级后续更新不改变已有输出像素，只标记直接子级。输入检查显示来源路径和具体版本；工程包包含输入快照及全部引用资产。
- 归档通过现有禁工具文本助手生成修改意图，不声称未经验证的图像差异。成功后跳过该节点；后代更新使用最近未归档祖先及顺序说明。说明可编辑，节点可解除归档；不自动重生图片。摘要期间工程变化则拒绝过期归档。
- 默认 2 份备份，不计当前；设置范围 0..100。满额在生图前拒绝，可启用自动删最旧、手动移除或本节点 +3。独立容量在数量降回系统上限时恢复跟随。自动清理仅在新结果成功发布后进行。
- 备份可只读预览和导出；“以此备份继续编辑”复制其配置为工作草稿，预览所选备份，更新产生新的不可变资产。当前结果在发布时进入历史，旧备份不覆写。备份计数限制是可切换历史数；被引用的文件及任务证据不会物理删除，保证溯源。
- v0.20 工程读取时兼容迁移，版本 ID 从既有节点 ID/像素哈希稳定派生；保存工程时落盘，不覆盖原图。

验证：scripts/Test-BoardWorkflow.py（零模型状态/容量/归档/包往返）、Test-BoardInvariants.py（队列取消/冻结输入）、Test-PostProductionBoards.py（HTTP/worker/像素/PSD/导出；--images 一次真实图片）、web/postproduction/test-workflow-dom.cjs（jsdom 组件事件，非浏览器视觉验收）。当前仍不生成分层结果 PSD；图像几何及风格仍需人工检查。


## 画布操作与编辑历史（v0.22）

- 单击只选择；“定位选中图”明确缩放到选择。“适应全部”和“整理布局”分开，布局不改变图片或输入身份。
- 右键拖动平移，各工具下均有效；使用 Pointer Capture，离开画布/取消可释放。移动超过4像素不弹出菜单，原地右键仍显示节点菜单。平移不进入编辑历史。
- 列表及大图预览各自可上下滚动。默认滚轮切换上一张/下一张；工具栏“平滑”或设置→列表预览区滚轮可切为多图连续浏览；不改变画布滚轮缩放。
- 删除按钮/右键菜单/Delete打开删除确认；删除节点及后代，保留图片和逻辑来源，Ctrl+Z或撤销按钮恢复，Ctrl+R或重做按钮再次执行。输入框内 Ctrl+Z 留给文字编辑，Ctrl+R由工作台接管，阻止浏览器刷新。
- 历史随本机工程原子保存，最多30条且受12 MB元数据预算限制。新建白板、删除、位置/理解框/参数、折叠与布局均可撤销重做；相机和选择不记录。新编辑清空 redo。任务进行/待复核时阻止历史回放。实际生图发布是历史边界；恢复图片使用前述不可变备份，不通过 Undo 伪造一次生图。
- 理解框为主体实体边界。按有效父子深度分列、按子树高度排布，横向140、纵向90逻辑像素间距；不同根节点独立成树。新建自动整理；移动时固定所拖节点，其他相撞主体向下避让；调整理解框同样避让，参考图跟随其主体平移。
- 画布拖动/缩放期间使用暂态布局，实时更新连线和相邻节点，结束才提交一次持久编辑。缩放反馈与Rect实际尺寸分离，避免反复放大。
- 每条子分支在父级理解框右边界有独立−/+端口，连接到子级理解框左边界。画布折叠状态按子分支独立保存，折叠/展开自动整理；列表以单独的−/+折叠树节点，互不修改状态。创建节点仅展开当前视图中的祖先路径。

验证：scripts/Test-BoardLayout.py、web/postproduction/test-layout.cjs 对齐Python/JS布局（80节点、12个连续拖动位置），以及 test-layout-dom.cjs 的实际Konva事件调用/React组件测试。后者模拟绘图上下文，不是浏览器视觉或鼠标硬件验收。


“平滑”开启后，所有当前列表项按顺序纵向排列为长页面；滚动仅浏览，点击才改变编辑对象。侧栏选中项会定位到对应卡片；每张卡片的“单图对比”可返回单图模式。开关持久保存，默认关闭。


## 白板与左侧定位（v0.22 补丁）

待生成节点的“结果”是空白，而非输入图副本。列表单图及平滑卡片默认左半白色/右半固定输入，拖动中线可检查；画布与资源缩略图为纯白。真实输入资产仍保留在元数据中，更新时照常使用，不写白色图片替换输入文件。

左侧“自动定位到图片”默认开启：在画布中选择侧栏项会缩放到对应理解框，若祖先分支被画布折叠则展开该路径；平滑模式会滚动到对应卡片。关闭后侧栏只选择，不移动画布/滚动位置。直接点击画布始终不自动缩放。列表的−/+按钮固定显示于行首，叶子行只预留空位；与右下角悬浮定位按钮分开。搜索时折叠也生效。


非平滑切换保留同一预览区域的测量尺寸，等待结果/输入解码后用140ms透明度过渡；不缩放动画，迟到加载不会覆盖新选择。工具栏固定高度，白板提示不挤压图片区域。平滑模式中已生成子图也直接展示结果/固定输入的左右对比及可拖动中线，原始根图没有伪造的比较对象。

## 输入模板、删除与参数默认值

删除确认可勾选“不再提示”，仅确认删除时生效；在设置中可以恢复提示。删除仍可撤销。每项参数旁提供恢复默认按钮；整体恢复默认保留描述、标注和参考图。原始输入不能直接更新图片，需创建子级；完成结果仍须解锁才能改生成内容。

## 画布小工具修复

工具栏选择／平移始终可用；画笔、箭头、文字、Label、可修改区域、保护区域和理解框作用于实际点击的主体图。选择已锁定结果时，工具栏显示提示和解锁按钮，解锁后理解框控制柄立即出现。原始输入不需解锁。标注与文字固定归属目标图，防止绘制到之前选中的图；笔点按可留点，取消手势不保存残笔。

## 标注的二次编辑与笔刷

选择工具可点选已有笔迹、箭头、文字、Label、可修改区和保护区；选框角点用于等比缩放，拖动标注只移动标注。点击空白处或按 Esc 取消选择。文字／Label 双击修改，也可在标注面板点“修改文字”。列表中的标注名称同样可选中对应标注。

画布工具栏下方提供笔刷大小滑块、数值和恢复默认。绘画时设置新笔刷大小，选中标注时调整该标注的粗细／文字大小；右侧标注页同步。选中标注后 Delete 只删除该标注，Ctrl+Z／Ctrl+R 撤销／重做；修改自动保存并使所属图片变黄。已完成结果仍需解锁内容，原始输入不需解锁。此版支持移动与等比缩放，不存储仅浏览器可见的变换。

## 文字原位编辑

双击文字／Label 直接在画布原位置输入；新建文字／Label 和右侧“修改文字”也使用同一原位输入方式，不再弹出文字对话框。编辑时隐藏对应旧文字，输入框随相机缩放与位置对齐。Enter 换行，点击外部或 Ctrl+Enter 保存，Esc 放弃本次编辑。清空已有文字并完成编辑会删除该文字；空白或取消的新建不创建标注。保存后继续支持原有选择、移动、缩放、撤销和自动保存。

## 空间考虑框与画布资源（当前规则）

- T 是无底色文字；Label 是有底色和边框的标签。两者均可双击原位修改。
- 新画的修改区／保护区松开后自动闭合，以浅绿色／红色斜线 Hatch 显示。真正的生成遮罩填满闭合区域内部，保护区优先；旧工程的线状遮罩不被重新解释为多边形。
- 新标注存储为画布世界坐标的独立资源；框外照常可画、可写、可移动、可粘贴。旧标注继续显示，不再被其存储节点的框裁掉。
- 画布粘贴／拖放普通图片默认是参考资源，不是新的计算主体；不会自动扩大主图的考虑框。显式顶部导入仍可建立主体图。资源本身没有考虑框。
- 标注和参考图与主体的关系由空间范围决定，不再是固定父子关系。框内相交部分参与对应图更新，参考图按相交部分裁取；移到框外后不参与。图片像素仍是原来的目标裁切，考虑框只扩大输入上下文。
- 移动主体时，移动前已吸纳的资源随主体一起移动；框外资源保持世界位置。若一个资源跨越多个不相交框，移动时以重叠面积最大的框为主，生成时各框仍读取各自相交部分。
- 待生成白板可点“应用父级”，将固定的父级底图填入。它仍是未锁定的待更新草稿，不调用模型、不伪造生成版本，支持撤销。
- 整图更新的附件包含干净目标图、完整考虑框示意图、像素遮罩和编号参考板；示意图保留文字、箭头、参考图的实际相对位置。另传归一化坐标，说明箭头从哪里指向哪里。模型根据这些视觉／文字指令理解应用关系，不能保证每次推断完全符合设计意图。
- 新标注／参考图修改先做整图更新，再做已确认整图的高清细化；高清入口发现未经整图确认的上下文会明确提示。每个考虑框当前最多四张参考图；画布可保存更多框外资源。
- 资源是共享画布内容，取消某张图的参数编辑不会删除或回滚共享资源。资源编辑可使用画板 Undo／Redo；生成输入快照和历史版本保持独立。

### 删除选中的标注

选择工具点选文字或其他标注后，键盘 Delete、顶部“删除”、右侧“删除标注”、标注行的 × 和标注右键菜单均只删除该标注，支持 Undo。右键选框控制柄也按标注处理。未选标注时，图片的删除仍走原有子树确认流程。文字输入期间 Delete 编辑字符；要移除整条标注可点击对应删除按钮，失焦不会把已删除文字重新写回。

## 边界、内容锁与参考图框

考虑边界不受内容锁定限制。点击“调整考虑边界”即可拖动／缩放，列表模式下也会直接进入画布。参数、描述与既有图内内容仍按内容锁保护；生成图解锁后可点“锁定编辑”，保留已改参数／描述，不必用取消操作重新上锁。原始输入模板仍保持可编辑；正在生成时暂停边界调整。

左侧主体列表和数量只包含计算主体。粘贴资源不进入列表；通过画布右键、选中素材时的工具栏或参考图缩略图的转换按钮，显式“转换为输入图”后才成为主体。转换保持相同 ID 和图片资产，可 Undo 恢复为资源。

考虑框捕获的资源显示在右侧参考图框，生成／标注／历史页均可查看，不被主体内容锁禁用。点击缩略图选中对应画布素材，点击画布素材也会高亮对应缩略图，并保留当前主体的设置页；选中后可调整参考用途。× 从画布删除该资源，支持 Undo，主图布局不变。右上方“◎ 自动定位”独立开关默认关闭，开启后点击缩略图会在画布定位该素材，不影响左侧列表自己的自动定位设置。素材未被当前考虑框捕获时，不出现在该参考图框。


## PhotoCraft 编辑参考层（2026-11-08）

选中主体图或画布参考图片，点击顶部 **PhotoCraft 编辑**，在工作台内打开本机浏览器版编辑器。首次以当前图片的合成像素建立独立 PSD 编辑副本（Source reference + 透明 Annotations 层），不会打开或改写原始 PSD 的图层结构。可使用 PhotoCraft 原生画笔、文字、图层等基础功能。完成后点击 **应用并返回**；取消编辑不改变已应用的参考层。

每个对象只有一份 `editReference`：保存当前可继续编辑的 PSD 项目及其全尺寸 PNG 合成参考图。再次打开载入该项目；再次应用替换这一份。它不进入生成图的 versions，也不随画板 Undo/Redo 切换。原图 asset、来源、父级及版本编号不变。编辑参考层可以停用、启用、删除；点击缩略图可与原图拖动对比。画板保存/另存为/工程包包含当前项目与参考图，编辑器取消/应用后的临时文件会清理。

整图生成仍使用原来的干净父级图片。当前图的编辑参考层优先，否则使用有效父级的这一份参考；它作为对齐的 `edited-target` 指引进入编号参考板与空间图，不替代干净输入，也不直接混进导出结果。画布参考资源的编辑层只影响该资源作为参考时的内容。参考预算仍为最多四张（含编辑参考层）。新指引须先经过整图更新，再进入高清细化；本次没有额外消耗 AI 生图额度验证指令遵循效果。

原图像素变化后，旧层暂停参与生成；再次打开从当前图建立新副本，应用后替换旧层。并行会话不会覆盖更新后的来源/参考层；备份查看期间不能编辑当前参考层。项目限制为 PSD、256 MB、8192 px/边，使用 PhotoCraft 的全尺寸兼容合成图，不拿缩略图放大假充。PhotoCraft 原生功能能否完整往返取决于其 PSD 支持；此入口定位为基础编辑/标注，不承诺所有高级特效无损。

PhotoCraft **0.21.0** Web/Wasm 随插件部署，本机按需启动，无需安装真正的 Photoshop，也不新增外部云端编辑服务。浏览器需 WebGL2；冷启动可能需要等待。保留原版程序和品牌，SceneFlow 仅提供独立宿主适配器。来源与逐文件 SHA：`PostProduction/vendor/photocraft/SCENEFLOW-SOURCE.json`；许可证与归属说明同目录。


### 编辑参考层的小眼睛

编辑参考层现在默认直接显示。选中带编辑层的图片，在右侧 **编辑参考层** 标题旁点击小眼睛，可隐藏／显示该图的编辑层。列表结果画面、平滑连续列表、画布和左侧缩略图共享这一设置；对比中的右侧输入图保持原始像素。透明部分仍显示原有结果，叠加层不拦截选择或拖动。

这是预览开关，与 **启用／停用 AI 参考** 分开：隐藏不会停止它参与生成，也不会改动原图、导出像素、参数或历史备份。显示状态自动保存，再次打开页面或再次编辑并应用时仍保留。不需要解锁内容即可切换。过期引用、只读备份和空白待生成结果不会套上当前编辑层。

本轮流程调整见 [AI 后期任务流程 0.22.1](Task-Workflow-0221.md)。


### PSD participation and independent channels (0.22.14)

In a source PSD or a draft using that PSD as its direct input, the right-hand
Generate pane exposes **PSD / AI participation**, outside Advanced settings.
Each row has a participation checkbox and a usage selector. Defaults follow
`effectiveVisible` from the imported PSD (including ancestor visibility).
Switching a group gates its descendants; enabling a child enables its ancestors.
All / None / Restore defaults, auto-save, board Undo/Redo and child/sibling
parameter inheritance use the existing board configuration model. Completed
content locks still apply. Text-input Undo remains local; checkbox/range focus
no longer blocks board Ctrl+Z / Ctrl+R.

A visible, disabled layer protects its visible composite pixels. It is not
removed from the clean source. Explicit enabled Exclude retains the existing
recomposite semantics. Hidden layers remain hidden in that clean source and mask;
enabling one supplies an independent reference instead of changing PSD eyes.
The original PSD is never written.

Known channel names suggest purposes: Arctic/form, depth, material-region colours
and shadow/lighting. Explicit Editable overrides remain authoritative. Worker
extraction validates the PSD hierarchy and supported pixel/blend/group features,
reads one private PSD snapshot, and groups selected guides into a bounded sheet.
Its full-document cells have the same camera/proportions and a numbered manifest.
Normal visible Editable layers continue through the clean image/edit mask;
Structure/Reference and enabled hidden layers can supply separate guide pixels.

Whole-image execution appends the channel sheet to its actual image attachments,
after the optional spatial reference sheet. Preflight exposes the same channel
sheet and manifest under **PSD guides**. This adds image context, not an extra
image-generation request and not ControlNet/hard geometry enforcement. Explicit
pixel protection remains enforced during backfill. A PNG/result parent does not
reacquire its coarse ancestor PSD; HD continues from the approved anchor.
