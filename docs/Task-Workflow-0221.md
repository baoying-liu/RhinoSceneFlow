# AI 后期任务流程 · 0.22.1

本轮依据 2026-11-09 的整体审计调整现有工作台。列表、画布和文件格式保持兼容，没有替换原图、重排来源关系或增加新的 MCP 监听器。

## 操作

- 原图：创建方案。原像素只读，模板设置可编辑。
- 完成图：继续修改创建整图子级；另一方案创建同级；高清输出创建以该结果为输入的高清草稿。创建草稿不调用模型，不消耗原节点的备份。
- 高清草稿：保留所选结果的参数，描述为空；允许直接确认高清，不要求编造新描述。新的空间修改仍需先完成整图，保留原有 HD 上下文保护。
- 待生成草稿：描述和处理方式置于右侧上方；输入摘要常驻，显示干净缩略图、文件名和版本。高级参数、参考与标注、任务与显示选项折叠；标注操作自动打开对应内容。
- 白板可显式选择“用输入图辅助标注”，调用已有 applyParent；仍是待生成草稿，不能冒充 AI 结果。
- 解锁/重做、放弃草稿、锁定、混合比例等放到任务与显示选项。混合比例明确是像素呈现，不声称模型编辑强度。参考叠加显示时底栏明确提示不包含在导出里。
- 原图、黄色待生成、紫色上游输入变化保留文字状态。已完成备份的只读预览不能直接触发生图动作。
- 父子连线稳定使用关系线颜色，选中图的直接关系高亮，其他关系淡化；不再用草稿黄线混淆默认的标注箭头。端口、实时跟随和独立折叠不变。

## 实际输入检查

`POST /api/boards/{board}/nodes/{node}/preflight {revision,stage}` 通过现有原厂 Platform 的 postproduction_request 可调用，无新 transport。

后端 generation_snapshot 是 preflight 和 start 的共同输入解析器：使用最新有效父级，正确穿过归档步骤并附加修改说明；已有左右对比仍使用生成时固定的输入，不偷偷改历史图。

整图检查在已有独立 raster 子进程生成干净输入、考虑框图示和真实回填 mask，返回哈希资产、实际纳入的标注/参考（含编辑参考层）、可修改像素和 revision。白可改、黑保留。检查不修改 board、历史、结果或备份，不调用模型。

高清检查仅展示批准的输入 anchor；已批准的旧上下文不会被描述成额外发送的参考。新的上下文仍按原规则拒绝，避免无声忽略。

确认按钮提交被检查的节点、阶段和 revision；期间工程变化会拒绝，不把过期检查用到另一个任务。关闭或 Esc 取消检查后，迟到的响应不能重新弹窗。输入预览资产留在该工程的私有 assets/tasks 中，源文件不变。

分支路由新增可选 stage；阶段与高清输入资格在建立草稿前校验。旧调用省略 stage 时保留原参数继承语义。
