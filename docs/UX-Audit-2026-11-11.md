## Reproduced issues and fixes

1. **Installed Studio could not start.** Native 0.22.18 compared itself with a
   hardcoded Web service 0.22.16; restarting merely recreated the mismatch.
   Version.txt and the browser version now derive from Directory.Build.props.
   MSBuild writes the deployed service version; Build.ps1 rebuilds the browser
   and rejects a mismatched package. The next package version is 0.22.19.
2. **Running jobs still looked like unsubmitted blanks.** The preview toolbar,
   list/stage labels and inspector now show actual task phases above pending
   image hints. No percentages are invented. Real running-task browser checks
   exercised both whole generation and detail refinement.
3. **False save conflict after copying an active board.** A copy inherited its
   source board's runtime busy identity. Initial task recovery cleared it and
   advanced the revision after the UI had exposed an older editable snapshot.
   Copies now clear runtime locks; loadBoard recovers tasks before reading the
   editable revision. Unsaved data is still retained on genuine conflicts.
4. **English save state in a Chinese UI.** Status now stores a semantic key and
   translates at rendering time, so async completion cannot pin the old locale.

## Remaining UX opportunities

- Add a final PSD-composite preview alongside Rendered preview. They currently
  serve different purposes and can look different, making export feel uncertain.
- Add terrain snapping plus an explicit eye-height preset for perspective views.
  The camera in this test is actually 2.424 m above its local terrain, not 1.7 m;
  the earlier progress estimate was corrected. Retain the exact submitted view
  for this result rather than silently moving it after generation.
- Explain visible-layer participation more directly: disabling a visible layer
  preserves its pixels; enabling a hidden guide sends guidance without changing
  the source composite. A night transformation must not accidentally preserve
  the daytime shadow region.
- Offer export-name localization separately from canonical asset identity.
  Seasonal suffixes and channel/asset names in the PSD can remain Chinese even
  when the native interface is English. Do not rewrite existing user names merely
  to change the UI language.
- Named View export settings live outside the 3dm. A portable case handoff should
  include or explicitly import those settings; this run retains their JSON.

These are recommendations, not claims that those workflows were redesigned.
