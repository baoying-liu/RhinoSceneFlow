# 视图导出工作台（v0.10）

在 Rhino 执行 `RhinoSceneFlowPanel`。窗口只由命令或显式 API 打开，预览使用 Eto ImageView，不创建浮动 Rhino 视口。

## 每个 Named View 一张卡片

工作台按两列排列全部已命名视图，可滚动查看。每张卡片有独立预览图、是否导出、预览显示模式、刷新按钮和输出宽高。刷新 Named Views 按稳定 ID 合并配置；刷新全部预览会逐张更新。

1K、2K、4K、8K 将**长边**设置为 1024、2048、4096、8192，按当前宽高比计算短边。也可直接输入宽高，每边范围 64–8192 像素。“像素”行的复制、粘贴只复制宽高。

## PSD 图层配置

卡片列表从上到下就是 PSD 图层从上到下。新建视图默认是阴影（正片叠底）、材质贴图；可添加空行，再下拉选择独立通道或 Rhino 原生显示模式。每行支持启用、上移、下移、删除、混合模式和不透明度（0–100%）。启用的空行会阻止导出，必须选择内容或禁用 / 删除。

支持正常、正片叠底、滤色、叠加、变暗、变亮。混合模式与不透明度写入真实 PSD 元数据，合成预览使用相同公式。“材质贴图”保存为一个“材质”分组，默认同一有效 Rhino 渲染材质 ID 合并为一层。选择“按物件分开”后，每个可见物件独立成层，仍直接放在同一个分组内；物件名附短 ID，避免重名混淆。物件材质与从图层继承的材质共用同一解析流程；同名但 ID 不同的材质不会误合并。

材质贴图读取已有真实世界 UV、贴图尺寸变换和颜色图片，输出不含光照的底色；阴影、反射不会烘入这一通道。可把独立阴影放在上面用正片叠底控制。原“图层颜色”通道保留按图层 RGB 合并的平涂输出，旧配置不迁移；旧 API 的 `kind:material` 仍表示图层色，新贴图使用 `kind:texture`。

首版支持不透明颜色位图及实体颜色、平面/箱体/圆柱映射、网格/曲面/Brep/SubD。缺失图片、失效的 SceneFlow 米制 UV、透明材质、透明 PNG、块实例与 Brep 面级多材质会明确报错；导出不会补算或改写对象 UV。程序纹理、玻璃与透明植物裁片不在本版支持范围。每张源图最多 8192×8192，场景源图解码合计上限 512 MiB。

“PSD 图层”行的复制配置、粘贴只复制图层列表、顺序、启用状态、混合模式、不透明度、材质分层方式，与尺寸复制互相独立；不会复制相机、太阳或预览模式。复制内容存放在插件进程内，采用深复制，不占用系统剪贴板。

原生显示模式从当前 Rhino 枚举，支持着色、渲染、极地等，也可选已安装的自定义显示模式。渐进式 Raytraced 暂不列入，因为一次视口捕获不能保证完成收敛。原生显示模式按 Rhino 自身效果捕获；独立阴影通道为直接日照单色遮罩，不含反射、GI、AO。

## 细节调整

双击预览，或点击“细节调整”，在同一窗口进入细节页。拖动图像旋转、滚轮缩放，或输入水平旋转、俯仰、缩放、目标平移 XYZ；可切换预览模式，并选择文档太阳或独立太阳方位 / 高度。太阳设置同时作用于该视图的显示模式捕获和独立阴影。

这些覆盖参数仅用于该视图预览与导出，不会直接改动保存的 Named View 或全局太阳。只有明确点击“写回 Named View 相机”才更新原 Named View；太阳不会随该按钮写回。

## 批量导出与保存

选择文件夹后导出勾选视图，每个视图一个同名 PSD。全部尺寸和配置先校验，再处理重名：是覆盖，否自动添加 001、002……，取消中止预检。最终 PSD 原子替换；取消时清理尚未完成的临时文件，已经完成的前面视图保留。

几何和原生显示模式捕获在 Rhino UI 线程完成，几何投影、阴影与 PSD 写入后台处理。原生显示模式捕获本身仍可能短暂阻塞 Rhino；大场景、8K 和多个渲染模式耗时取决于场景及硬件。几何通道使用带边界重叠的分块和磁盘暂存，避免同时分配整幅 8K 阴影缓冲。PSD v1 仍有约 2 GB 限制，过多图层或高分辨率会明确拒绝；暂不支持 PSB。

配置自动保存于 `%LOCALAPPDATA%/RhinoSceneFlow/workbench/`，已保存文档按完整路径散列区分，未保存文档按进程和文档序号区分。保存工作台设置不会把 Rhino 文档标为已修改；移动 / 重命名文件会形成独立配置，未保存文档不承诺跨 Rhino 重启恢复。图层配置不写入 3dm 文件。

布局、关联裁剪平面的视图仍不支持。旧 `export_named_views` 和单视图命令保留原来的 800 万像素限制；新工作台及 `export_workbench` 支持每边最高 8192。

## 自动化与验证

使用原厂 Rhino-MCP-Platform 调用公开 JSON API，见 [MCP 文档](MCP.md)。新增 `workbench_settings`、`configure_view`、`export_workbench`，不启动额外服务。

`Test-Workbench.py` 测试真实 Eto 控件与导出；`Verify-Workbench.py` 用 psd-tools 独立解码并重新合成。`Test-WorkbenchDetails.py` 测试临时 Named View 写回和布局；`Test-WorkbenchAsync.py` / `Check-WorkbenchAsync.py` 分两次调用验证真实异步导出，禁止在 Rhino UI 线程等待任务完成。所有原生测试固定在 B 通道。

取消测试在启动脚本前设置 `System.AppDomain.CurrentDomain.SetData('WorkbenchTestCancel', True)`，启动 / 查询同上。`Test-Workbench8K.py` / `Verify-Workbench8K.py` 验证真实 8192×2048 材质导出；`Test-WorkbenchWindows.py` 验证三次开关后无额外视图；`Test-WorkbenchFinal.py` 验证最终构建的滚轮事件、全卡片预览与组合 PSD。测试模型使用当前自有测试文档，首次装载可复用 `Test-Workbench.py` 的 File3dm 导入；不得把含旧浮动视图的完整 3dm 视图表恢复进主文档。
