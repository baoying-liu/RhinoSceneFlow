# Introduction revision v03 — editorial reset

This delivery is a keyframe review and two motion tests, not a replacement full-length film. The previous v02 MP4 is retained as an earlier draft.

## What changes

1. One operation per beat. Explain the real entry point before the result; do not invent shortcuts, progress or one-click planting from chat.
2. Assets: select targets, generate/reuse in AI Assets, then apply to object/layer. Plant generation creates library resources; placement and group editing occur in Plants Library and Plants List. Native UI interaction footage still needs fresh English captures before final editing; these keyframes explain the steps without fabricating a new control panel.
3. Camera: the old 120 captures per revolution were 3 degrees apart and opacity-blended. That is not native per-output-frame motion and can produce double contours. New test: 180 actual Rhino captures at the 180 output frame positions, 48-degree eased arc over six seconds, no opacity interpolation, no optical-flow reconstruction. The final film should use short purposeful arcs, match camera positions across material/season cuts, and avoid repeated full rotations. Do not certify visual smoothness from frame count alone; review the test clip.
4. PSD: restore the original exploded-layer concept with a familiar right-side layer list. First show the intact PSD, spread layers, then pull out one selected layer at a time while highlighting the matching row. Hold each channel long enough to see its role. Restore the stack before moving to Web. The editor is conceptual; pixels are actual exported channels.
5. AI: import the PSD, create a proposal, edit brief and participation, check input, confirm generation. Do not present generation as immediate. Keep whole-image approval and HD refinement separate.
6. Results: use the actual Web Compare divider on matching source/result views. Sweep slowly, pause on roof edges, windows, paths and tree positions, then reveal the whole result. Keep the retained Monet/daylight and restrained architectural styles. Exclude magenta/cobalt, coral/gold and turquoise-oil color studies from the revised cut. These comparisons reveal differences; they are not a geometry guarantee.
7. Canvas: select a result, create a child, use the input as annotation background, draw actual edit/protect instructions, add arrow/text/reference context, check input and generate. Preserve visible ancestry. Keyframe 07 currently establishes ancestry; a complete annotation interaction recording remains a final-edit capture item.
8. Approve the whole image before making the 4K child. Keyframes 05–08 now use the same Garden camera and its actual corresponding 4096×2304 result, avoiding the previous switch between unrelated views.
